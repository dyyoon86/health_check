## 매일 공통 [기본] — 약 15분 (운동 없는 날도 반드시)
1. 스트레칭 각 30초 × 2회
   - 햄스트링: 다리 펴고 앉아 상체 숙이기 (측정 자세 그대로)
   - 허리: 네발 기기 자세에서 등 둥글게/펴기 (고양이 자세)
   - 종아리: 벽 밀며 뒷다리 펴기 (좌우)
   - 허벅지 앞: 서서 발목 잡고 뒤로 당기기 (좌우)
   - 고관절: 앉아서 발바닥 붙이고 무릎 내리기 (나비 자세)
2. 교차윗몸일으키기 (기간별)
   - 10/2~10/11: 할 수 있는 만큼 × 2세트
   - 10/12~10/18: 30초 최대 × 3세트 (휴식 1분)
   - 10/19~11/1: 60초 최대 × 3세트 (휴식 1분)
   - 11/2~11/9: 60초 × 1세트

## 운동 코드
모든 운동 전 준비운동 5~10분(제자리걷기, 발목·무릎·허리 돌리기, 가벼운 스트레칭)

**A = 유산소**
| 기간 | 내용 |
|---|---|
| 10/2~10/11 | 빠르게 걷기 30분 (숨차지만 대화 가능) |
| 10/12~10/18 | [걷기 2분 + 조깅 1분] × 8회 → 걷기 5분 |
| 10/19~10/25 | [걷기 1분 + 조깅 2분] × 7회 → 걷기 5분 |
| 10/26~11/9 | 조깅 15분 연속 → [빠르게 30초 + 걷기 1분] × 5회 → 걷기 5분 |

**B = 근력·순발력·민첩성**
| 기간 | 내용 |
|---|---|
| 10/2~10/11 | 맨몸 스쿼트 10회×2 · 벽 푸시업 10회×2 · 악력(악력기 or 수건 비틀어짜기) 좌우 15회×2 |
| 10/12~10/18 | 스쿼트 15회×3 · 무릎 푸시업 10회×3 · 악력 좌우 15회×3 · 데드행(철봉 매달리기) 최대×2 · 멀리뛰기 50% 힘 자세연습 5회 · 10m 왕복 걷듯이 방향전환 연습 3회 |
| 10/19~10/25 | 스쿼트 15회×3 · 스쿼트점프 8회×2 · 악력 좌우 20회×3 · 데드행 최대×3 · 멀리뛰기 80% 5회 · 10m 4회왕복 70% 속도 ×3 |
| 10/26~11/1 | 위와 동일 + 멀리뛰기 90% 5회 · 10m 4회왕복 80~90% ×4 |

**C = 셔틀런 실전 연습**
준비운동 10분 → 유튜브 "20m 왕복오래달리기 음원" 틀고 20m 구간 왕복 → 신호음 2번 놓치면 종료 → **횟수 기록**

**W = 회복** : 편하게 걷기 20분 + [기본]
**X = 휴식** : [기본]만

**M = 모의 측정** : 체중 · 악력(가능하면) · 윗몸일으키기 60초 · 유연성 · 멀리뛰기 2회 · 10m 4회왕복 · 셔틀런 → 전부 기록
